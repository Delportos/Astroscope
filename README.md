
Working on consolidation of current codebase and paying back technical debt before moving on. 


The ultimate goal of this program is to present the user with an interactive star map that connects to instrumentation or can be used without instrumentation and can be used with a keyboard and mouse. Ultimately, there will be a time when this repo is adapted and used for a handheld device, which will be planned for in advance as well as possible. 

Going forward, there will be a couple folders in this repository.
